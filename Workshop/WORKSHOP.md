# Steam Workshop package — Human Host Explosives

Everything needed to publish. **The upload itself needs your Steam account**, so that step is
yours; everything up to it is prepared here.

## Files to ship

```
HumanHostExplosives/
  HumanHostExplosives.dll          the plugin
  Assets/Anim/throwanim.bundle     throw animation (Unity 2022.3.62f3)
  Grenade/grenade.obj              held model
  Grenade/grenade.mtl
  Grenade/grenade.png              model texture
  Grenade/grenade_icon.png         inventory icon
```

Drop that folder into `Human Host/BepInEx/plugins/`. Requires BepInEx 5 (already required by the
other mods on this game).

## Title

    Explosives — Craftable Grenades

## Short description

    Craftable, throwable fragmentation grenades with a real throw animation. Damages players,
    creatures and buildings. Fully configurable.

## Description (Steam BBCode)

```
[h1]Explosives[/h1]
Craftable fragmentation grenades for Human Host — with a proper throw animation, real
structural damage, and everything tunable.

[h2]What it adds[/h2]
[list]
[*][b]Hand grenades[/b] you craft at the Gun Workbench, or find in loot.
[*][b]Hold to charge[/b] — throw distance scales with how long you hold the button.
[*][b]A real throw animation[/b] on the player character, with the game's own swing sound.
[*][b]Damage that lands[/b] — players, creatures, and buildings, through the game's own
structural damage systems, so walls break the way the game intends.
[/list]

[h2]Recipe[/h2]
[list]
[*]2 × Scrap Iron — the casing
[*]3 × Gun Powder — the filler
[*]1 × Duct Tape — holds it together
[/list]
Gun Powder is a Chemistry product, so grenades land as a mid-game craft rather than a
day-one item.

[h2]Loot[/h2]
Grenades are added to existing loot tags rather than given a new spawn rate of their own, so
they turn up only where that kind of item already appears, at that rarity — and they respect
your loot-rate setting and looting skill automatically.

[h2]Configuration[/h2]
Everything is in [i]BepInEx/config/com.nathanfeddema.humanhostexplosives.cfg[/i] — blast radius,
damage, self-damage, fuse, throw power, animation speed, release timing, sound, loot tags. Press
[b]F10[/b] in game to reload the config without restarting.

[h2]Requirements[/h2]
BepInEx 5. Singleplayer tested.

[h2]Known limits[/h2]
[list]
[*]Molotov is registered but disabled — waiting on a 3D model.
[*]Not tested in multiplayer.
[/list]
```

## Publishing

Human Host ships its own **ModBrowser** (`Human Host_Data/ModBrowser/`) with
`Config/mod_category.json` and `Data/installed_mods.json`, so the game has a first-party mod
listing — check whether it publishes through Steam Workshop directly or expects a manifest
before uploading by hand. If Workshop is the route, the usual path is the game's own uploader if
it has one, otherwise SteamCMD `workshop_build_item` with an app-specific VDF.

**[?] Not verified:** whether this game's Workshop accepts BepInEx plugin folders directly, or
expects a wrapper format. Confirm against a published mod for this appid before your first upload.
